# 🎰 Python Slot Machine Game

A fun and interactive slot machine game developed using Python. 
The game generates random symbols and allows players to earn points through matching combinations.

---

## 📌 Project Overview

The Python Slot Machine Game is a beginner-friendly project designed to practice Python programming concepts such as loops, conditional statements, random number generation, and user input.

Players spin the slot machine and earn points based on the symbols displayed.

---

## ✨ Features

- 🎰 Random symbol generation
- 🎮 Interactive gameplay
- 🏆 Points-based scoring system
- ❤️ Lives system
- 🔥 Winning streak tracking
- ⭐ Best streak tracking
- 🔄 Customizable number of rounds
- 🎨 Simple and engaging interface

---

## 🛠️ Technologies Used

- Python
- Random module
- Tkinter (for the GUI version)

---

## 🎯 Game Rules

- Three matching symbols: **+100 points**
- Two matching symbols: **+20 points**
- No matching symbols: **-5 points**
- Players can choose the number of rounds.
- The game tracks the player's score and winning streak.
